# Pricefy (Projetos_5)

Pricefy é uma ferramenta de comparação de preços desenvolvida em Python com Streamlit. Ela permite buscar produtos em diversas lojas online (como Kabum, Terabyte e via agregadores como o Zoom), apresenta os resultados ordenados com variação em relação ao menor preço e gráficos de comparação por oferta e por loja.

## Pré-requisitos

Certifique-se de ter o [Python](https://www.python.org/) instalado em sua máquina.

## Como iniciar o projeto

1. **Abra o terminal** e navegue até a pasta do projeto:
   ```bash
   cd projeto_5
   ```

2. **Instale as dependências** necessárias executando:
   ```bash
   pip install -r requirements.txt
   ```

3. **Inicie o servidor** do Streamlit com o comando:
   ```bash
   streamlit run app.py
   ```

4. **Acesse a aplicação**: O Streamlit abrirá o projeto automaticamente no seu navegador. Caso não abra, acesse a URL que aparecerá no seu terminal (geralmente `http://localhost:8501`).
